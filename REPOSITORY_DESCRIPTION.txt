--- Longer "About" paragraph (for a README header or repo social preview) ---
EP-PQC-001 tests whether an ExecutionProof-style gateway can enforce "if it cannot be verified, it
cannot execute" for post-quantum cryptography. The gateway re-derives the true algorithm family from
raw key bytes, recomputes artifact hashes, verifies a real ML-DSA-65 manifest signature, and checks
authority/freshness/binding/nonce/policy before a real ML-KEM encapsulation is allowed to cross the
boundary. Preregistrations are hash-sealed before execution; every decision emits a hash-sealed
ProofRecord; a standalone verifier re-checks the full chain. Verdicts are preserved verbatim (root =
PARTIAL/safety-PASS; R1 = PASS). This is a software simulation only — see the limitations section
before citing.
